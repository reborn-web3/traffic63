# Design Source of Truth (traffic63)

## 1. Визуальный стиль
- **Общее настроение:** Премиальное, высокотехнологичное, но с человечным "cozy" оттенком (агентство для людей, а не бездушная корпорация).
- **Цветовая палитра:** 
  - Основной акцент: Насыщенный синий (Ink Blue `#2563eb`) и коралловый.
  - Фон: Чистый белый (`#ffffff`) или "бумажный" (`#f8f9fa`) для обеспечения максимального контраста и чистоты (Light theme).
- **Типографика:**
  - Заголовки: Geist (или строгий sans-serif) для передачи технологичности.
  - Текст: Nunito для читабельности.
  - Акценты: Caveat (рукописный) для создания эффекта персонализированного подхода ("doodle/handwritten" элементы).

## 2. Анимации и Микроинтеракции (Framer Motion)
- **Плавность:** Все переходы и hover-эффекты должны быть плавными (spring/ease).
- **3D и Интерактивность:** Как в Hero Dashboard, использовать слои, псевдо-3D эффекты (offset тени) и параллакс при скролле.
- **Scroll-reveals:** Элементы должны аккуратно появляться при скролле (fade-in, slight slide-up).

## 3. UX и Конверсия
- **Призывы к действию (CTA):** Кнопки должны быть контрастными, привлекать внимание, иметь явный hover-state (например, увеличение тени, смещение).
- **Структура блоков:** Свободное пространство (Negative Space) — ключ к премиальности. Не перегружать секции информацией.
- **Читабельность:** Контраст текста и фона должен строго соблюдаться (соответствие a11y). Рукописные шрифты использовать только для крупных декоративных заметок, а не для основного текста.
