# Инструкции по поведению (Workspace Agent Rules)

## Автоматическое делегирование (CEO Subagent Routing)

1. **Ключевые слова-триггеры**: 
   Если пользователь начинает свой запрос с одного из следующих префиксов (в любом регистре):
   * **`ceo `** или **`сео `**
   * **`/ceo `** или **`/сео `**
   главный агент **ОБЯЗАН** немедленно делегировать эту задачу сабагенту `ceo` с помощью инструмента `invoke_subagent`.

2. **Запрет на самостоятельное выполнение**: 
   Главному агенту строго запрещено выполнять анализ, писать код или тексты самостоятельно в таких случаях. Вся задача должна быть передана сабагенту `ceo` без предварительного чтения файлов главным агентом.

3. **Сопровождающее сообщение**:
   Перед вызовом сабагента главный агент должен написать короткое сообщение пользователю: *«Принято. Передаю задачу генеральному директору (ceo)...»*.
